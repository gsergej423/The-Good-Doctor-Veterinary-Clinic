# 🐾 ВетКлиника «Добрый доктор»

Одностраничный сайт (Landing Page) для ветеринарной клиники с интерактивной формой записи питомцев на приём. 
Выполнен в рамках Лабораторной работы №3 (Вариант 2).

## ✨ Основные возможности:
* **Форма записи**: сбор данных о питомце (имя, возраст, тип), владельце, номере телефона и описании симптомов.
* **Валидация данных**: проверка полей «на лету» (проверка на пустоту, минимальную/максимальную длину, корректность телефона и возраста).
* **Сохранение данных**: записи сохраняются в `localStorage` браузера, их можно просматривать и удалять без перезагрузки страницы.
* **Адаптивный дизайн**: сайт корректно отображается на мобильных устройствах, планшетах и ПК.
* **Безопасность**: защита от XSS-уязвимостей при выводе сохранённых данных.

## 🛠 Технологии:
* **HTML5** — семантическая разметка.
* **CSS3** — кастомные переменные, Flexbox, CSS Grid, адаптивность, анимации.
* **JavaScript (ES6)** — работа с DOM, валидация форм, работа с LocalStorage.

## 🚀 Как запустить:
1. Скачайте репозиторий.
2. Убедитесь, что файлы `index.html`, `style.css` и `script.js` находятся в одной папке.
3. Откройте файл `index.html` в любом современном браузере.
